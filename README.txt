MADAMJII BIRTHDAY WEBSITE
==========================

Files:
- index.html : complete mobile-friendly interactive website

How to preview:
1. Extract the ZIP.
2. Open index.html in Chrome or another browser.

Personalize:
- Search in index.html for “My dearest Mahazabin” and edit the letter.
- Edit the “Our little story” cards with your real memories.
- You can add a few photos by tapping the photo tiles in the browser preview. Those local previews are temporary and are not uploaded with the public site.
- For photos to appear to everyone on the public site, add image files to the same repository and change each photo tile to use <img src="your-photo.jpg">. Make sure Mahazabin is comfortable with any photo you publish.

Free publishing with GitHub Pages:
1. Create a free account at https://github.com/
2. Create a new public repository, for example: madamjii-birthday
3. Upload index.html (and any photo files you want public).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”; choose branch “main” and folder “/ (root)”, then Save.
6. Wait a little while. The Pages section will show the published URL, usually:
   https://YOUR-USERNAME.github.io/madamjii-birthday/
7. Open the URL on your phone to test it, then send it to Mahazabin at midnight.

Important:
- GitHub Pages hosting is free for public repositories; a custom domain is optional and costs money.
- Do not upload private or sensitive photos. A public repository/site may be visible to anyone with the link or who finds it.
- No account passwords, paid services, or external libraries are needed for this website.
